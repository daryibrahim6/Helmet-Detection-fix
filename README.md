# 🏍️ Helmet Detection System

AI-powered motorcycle helmet detection with **REAL-TIME WEBCAM**!

## ✨ Features

- 📷 **Image Detection**: Upload & detect instantly
- 🎥 **Video Processing**: Frame-by-frame analysis (browser-compatible!)
- 📹 **Webcam Real-time**: Live detection from your camera!
- 📊 **Statistics**: Compliance rates & metrics
- 💾 **Download**: Save processed results

## 📊 Model

- Algorithm: YOLOv8 Nano
- Training: 150 epochs
- Accuracy: 85%+
- Classes: helmet, no helmet
- Dataset: 761+ images (Indonesian traffic)

## 🛠️ Tech Stack

- Python 3.9+
- Streamlit
- YOLOv8 (Ultralytics)
- OpenCV
- FFmpeg (video conversion)
